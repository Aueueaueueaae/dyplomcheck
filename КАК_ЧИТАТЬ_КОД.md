# Как читать код этого бота

Это учебный пример Telegram-бота: он принимает `.docx`, разбирает оформление
и присылает отчёт. Бот не использует ИИ и не исправляет документ.

## С чего начать

Читать лучше в таком порядке:

1. **`app/__main__.py`** — точка входа, запускает `app/bot.py`.
2. **`app/bot.py`** — создание `Bot` и `Dispatcher`, настройка команд, polling,
   обработка ошибок сети и неверного токена.
3. **`app/handlers.py`** — всё общение с пользователем:
   - `/start`;
   - inline-кнопки;
   - приём `.docx`;
   - проверка размера и ZIP-структуры;
   - вызов анализатора;
   - отправка краткого и полного отчёта.
4. **`app/analyzer/document.py`** — самое технически интересное:
   - чтение OOXML;
   - абзацы и таблицы;
   - стили Word и их наследование;
   - эффективный шрифт, кегль, интервал, отступ;
   - секции и колонтитулы.
5. **`app/analyzer/profile.py`** — требования ГОСТ в виде чисел:
   поля, шрифт, кегль, интервал, отступ.
6. **`app/analyzer/engine.py`** — сами проверки:
   - поля;
   - шрифт;
   - абзацы;
   - заголовки;
   - нумерация;
   - рисунки;
   - таблицы;
   - литература;
   - ссылки.
7. **`app/analyzer/report.py`** — как нарушения превращаются в сообщение
   Telegram и полный `.txt`.
8. **`tests/`** — примеры корректного и «сломанного» документа, а также
   проверки основных функций.

## Поток данных

```text
Telegram
   ↓
handlers.py: принять файл
   ↓
analyzer/document.py: разобрать DOCX
   ↓
analyzer/engine.py: применить правила из profile.py
   ↓
models.py: список Issue
   ↓
report.py: краткий HTML + полный TXT
   ↓
Telegram
```

## Три вещи, которые важно понять

### 1. Бот не читает ГОСТ как текст

ГОСТ заранее переведён в правила. Числа лежат в `profile.py`,
логика проверок — в `engine.py`. Поэтому результат одинаковый для одного
и того же файла.

### 2. Word хранит форматирование не в одном месте

Итоговый шрифт собирается из:

```text
прямое форматирование → стиль символа → стиль абзаца → базовый стиль → docDefaults
```

Именно поэтому в `document.py` есть `StyleResolver`.

### 3. В DOCX нет готовых номеров страниц

Word пересчитывает страницы при открытии. Бот не может надёжно сказать
«страница 17», поэтому указывает номер абзаца и цитату.

## Как запустить

```powershell
.\setup.ps1
notepad .env
.\run.ps1
```

Для проверки файла без Telegram:

```powershell
.\.venv\Scripts\python.exe check_docx.py "работа.docx" -o report.txt
```

Для тестов:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

## Идеи для практики

- Поменять кегль или поля в `app/analyzer/profile.py`.
- Добавить новую проверку в `engine.py` и тест в `tests/`.
- Изменить текст главного меню в `handlers.py`.
- Добавить проверку формул или приложений.
- Сделать отдельный профиль под методичку конкретной кафедры.
- Добавить экспорт отчёта в HTML или `.docx`.
