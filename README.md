# DyplomCheck — Telegram-бот проверки оформления диплома

Бот принимает `.docx` с дипломной работой и присылает отчёт: где не тот шрифт,
сбиты поля, интервал, отступы, подписи, нумерация или список литературы.
**Бот ничего не исправляет в файле** — только показывает место, фактическое
значение и требование ГОСТ.

Бот: `@dyplomcheck_bot` (токен добавляется в `.env`).

Краткая инструкция для клиента: `ИНСТРУКЦИЯ.md` и готовый текст
для отправки — `ТЕКСТ_КЛИЕНТУ.txt`.

Если вы изучаете код: начните с `КАК_ЧИТАТЬ_КОД.md`.

---

## Что проверяется

| Блок | Проверка |
|---|---|
| Поля | A4, левое 30 мм, правое 15 мм, верхнее и нижнее 20 мм |
| Шрифт | Times New Roman, 14 пт; в таблицах допустим кегль не меньше 12 пт |
| Абзац | интервал 1,5; отступ первой строки 1,25 см; выравнивание по ширине; без лишних интервалов до/после |
| Заголовки | стили Word, без точки в конце, структурные — прописными, разделы с новой страницы |
| Нумерация | номер внизу по центру, на титульном листе не печатается |
| Рисунки | «Рисунок N — Название» под рисунком, по центру, без отступа и точки |
| Таблицы | «Таблица N — Название» над таблицей, слева, без отступа; нумерация |
| Литература | отдельный раздел, сквозная нумерация, базовая структура записи |
| Ссылки | `[N]` не выходят за пределы списка источников |

### Профиль ГОСТ

В основе — **ГОСТ 7.32-2017** «Отчёт о НИР. Структура и правила оформления»
и библиографические ГОСТ Р 7.0.100-2018 / Р 7.0.5-2008.

Важный нюанс: ГОСТ 7.32-2017 допускает кегль **не менее 12 пт** и называет
Times New Roman рекомендуемым шрифтом. В ТЗ заказчика зафиксирован вузовский
профиль: **Times New Roman 14 пт**, поля 30/15/20/20, отступ 1,25 см.
Именно он и проверяется. Если методичка кафедры отличается, значения меняются
в `app/analyzer/profile.py`.

Нормативные документы:

- [ГОСТ 7.32-2017](https://docs.cntd.ru/document/1200157208) — структура и оформление отчёта;
- [ГОСТ Р 7.0.100-2018](https://docs.cntd.ru/document/1200161674) — библиографическое описание;
- ГОСТ Р 7.0.5-2008 — библиографическая ссылка.

## Быстрый запуск (Windows)

Нужен Python 3.11+ (проверено на 3.13).

```powershell
cd C:\Users\Admin\dyplomcheck
.\setup.ps1
```

Затем откройте `.env` и вставьте токен от [@BotFather](https://t.me/BotFather):

```env
BOT_TOKEN=123456789:AA...
```

Запуск в консоли:

```powershell
.\run.ps1
```

Или в фоне (окно можно закрыть):

```powershell
.\start-bot.ps1
```

Остановить фоновый процесс:

```powershell
.\stop-bot.ps1
```

Логи фонового запуска: `bot-run.err`. Не запускайте `run.ps1` и
`start-bot.ps1` одновременно — Telegram не разрешает две копии одного бота.

Или вручную:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python -m app
```

Если PowerShell не даёт активировать окружение:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### Если `api.telegram.org` не открывается

Сначала проверьте:

```powershell
curl.exe --max-time 10 https://api.telegram.org
```

Если соединение зависает, бот не сможет подключиться. Нужен VPN или
HTTP/SOCKS-прокси, пропускающий обычный HTTPS-трафик. Прокси задаётся в `.env`:

```env
BOT_PROXY=socks5://127.0.0.1:1080
```

или

```env
BOT_PROXY=http://127.0.0.1:8080
```

Важно: TgWsProxy и подобные MTProto-прокси для Telegram Desktop **не подходят** —
это прокси для клиента Telegram, а не для HTTPS-запросов Bot API.

## Как пользоваться ботом

1. Отправить боту файл `.docx` **как документ** (не текст и не PDF).
2. Получить краткое сообщение: сколько ошибок и что исправить первым.
3. Скачать полный `.txt`-отчёт: все замечания, номера абзацев, цитаты,
   найденное значение и норма.

Команда одна: `/start`. Дальше — кнопки «Отправить работу», «ГОСТ и проверки», «Инструкция».

Ограничения Telegram: файл до 20 МБ. PDF и старый `.doc` не подходят —
в них нет стилей, шрифтов и параметров абзацев, поэтому проверка невозможна.

---

## Что бот не делает

- не исправляет документ и не присылает исправленный `.docx`;
- не проверяет смысл, орфографию, пунктуацию, уникальность;
- не видит точные номера страниц: `.docx` не хранит готовую разбивку,
  поэтому место указано номером абзаца и цитатой;
- не анализирует сноски, текст внутри фигур, надписей и верхние колонтитулы;
- не гарантирует прохождение нормоконтроля;
- не заменяет методичку кафедры.

## Где менять требования

`app/analyzer/profile.py`:

```python
body_font = "Times New Roman"
body_font_pt = 14.0
table_min_font_pt = 12.0
margin_left_mm = 30.0
margin_right_mm = 15.0
margin_top_mm = 20.0
margin_bottom_mm = 20.0
line_spacing = 1.5
first_line_indent_cm = 1.25
```

Шаблоны подписей и логика проверок — в `app/analyzer/engine.py`.
Если кафедра требует, например, 12 пт или другие поля, достаточно поменять
значения профиля и перезапустить бота.


## Проверка файла без Telegram

Удобно для демонстрации заказчику и отладки:

```powershell
.\.venv\Scripts\python.exe check_docx.py "Моя работа.docx" -o report.txt
```

Команда печатает полный отчёт и, если указан `-o`, сохраняет его в файл.
Код возврата `0` — ошибок нет, `1` — есть ошибки или файл не разобрался.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты собирают корректный и «сломанный» `.docx` и проверяют, что бот находит
поля, шрифт, интервалы, подписи, нумерацию и ссылки.

## Хостинг

Бот работает через long polling, поэтому нужен постоянно включённый компьютер
или сервер. Файлы сохраняются только во временную папку на время проверки
и удаляются в `finally`, база данных не используется.

Для Windows можно добавить `run.ps1` в Планировщик заданий при входе.
Для Linux/VPS — запускать `python -m app` через systemd с `Restart=always`.
Токен храните только в `.env`, не в коде и не в git.

## Если что-то не запускается

- `BOT_TOKEN не задан` — откройте `.env` и вставьте токен после `=`.
- `Conflict: terminated by other getUpdates` — запущена вторая копия бота;
  остановите её.
- `Нужен файл .docx` — пересохраните документ в Word:
  «Файл → Сохранить как → Документ Word (*.docx)».
- `Не удалось открыть файл как .docx` — файл повреждён или защищён паролем.
- Бот не отвечает — проверьте интернет, токен и консоль с логами.
